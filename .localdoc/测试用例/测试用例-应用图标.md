# 测试用例：应用图标

## 测试范围

验证 SVG/ICO 图标资源、Qt 运行时图标、Windows EXE 图标以及现有业务测试不受影响。

## 用例列表

### TC-001: 图标资源存在
- 前置条件：完成构建前资源接入。
- 操作步骤：检查 SVG、ICO 和 Qt/Windows 资源配置文件。
- 预期结果：资源文件存在且被 CMake 纳入目标。
- 优先级：P0

### TC-002: 运行时窗口图标
- 前置条件：构建应用并启动 Qt 应用。
- 操作步骤：观察窗口标题栏和任务栏图标。
- 预期结果：显示新生成的 XML 转 Properties 图标。
- 优先级：P0

### TC-003: Windows EXE 文件图标
- 前置条件：完成 Release 构建。
- 操作步骤：在资源管理器中查看 `xml2prop.exe` 文件图标。
- 预期结果：显示新图标，且不是默认 Qt/应用占位图标。
- 优先级：P0

### TC-004: 现有功能回归
- 前置条件：资源接入完成。
- 操作步骤：执行项目完整 CTest。
- 预期结果：全部已有测试通过。
- 优先级：P0

### TC-005: 小尺寸可辨识性
- 前置条件：查看 ICO 中 16×16、32×32 和 48×48 图像。
- 操作步骤：检查 XML 符号、转换方向和 Properties 键值元素。
- 预期结果：主体元素没有明显裁切或不可辨识重叠。
- 优先级：P1

### TC-006: Qt 资源图标自动化加载
- 前置条件：完成测试目标构建，且 `assets/resources.qrc` 已接入 QML 冒烟测试目标。
- 操作步骤：执行 `Xml2PropQmlSmoke` CTest；测试从 `:/icons/xml2prop.svg` 构造 `QIcon`，并请求 32×32 pixmap。
- 预期结果：`QIcon` 非空，且返回的 pixmap 非空并具有正的宽高。
- 优先级：P0

## 测试命令

```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

通用 / 桌面应用资源与构建验证。
