# 测试用例：忽略根节点

## 测试范围

验证转换器的根节点路径选项、根节点内容过滤、QML 复选框默认状态及现有功能回归。

## 用例列表

### TC-001: 默认忽略根节点
- 前置条件：加载主窗口。
- 操作步骤：查找“忽略根节点”复选框。
- 预期结果：复选框存在且默认勾选。
- 优先级：P0

### TC-002: 勾选时去掉根节点路径
- 前置条件：复选框保持勾选。
- 操作步骤：转换 `<root><value>ok</value></root>`。
- 预期结果：输出 `value=ok`，不包含 `root.`。
- 优先级：P0

### TC-003: 取消勾选保留根节点路径
- 前置条件：输入 `<root><value>ok</value></root>`。
- 操作步骤：取消勾选并转换。
- 预期结果：输出 `root.value=ok`。
- 优先级：P0

### TC-004: 忽略根节点自身内容
- 前置条件：复选框勾选。
- 操作步骤：转换 `<root flag="x">text<value>ok</value></root>`。
- 预期结果：只输出 `value=ok`，不输出根属性和根直接文本。
- 优先级：P1

### TC-005: 现有转换规则回归
- 前置条件：使用转换器单元测试。
- 操作步骤：运行属性、重复兄弟节点、转义、空节点、非法 XML 和 UTF-8 文件测试。
- 预期结果：全部通过，原有行为不变。
- 优先级：P1

## 测试命令

```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```
