## 决策列表

### DEC-001: 采用完整 Windows 图标接入
- 阶段：方案设计
- 背景：用户要求应用生成图标，需要覆盖桌面应用常见展示位置。
- 可选方案：仅生成素材；仅设置 Qt 运行时图标；同时设置运行时图标和 EXE 文件图标。
- 最终选择：同时设置 SVG/ICO 素材、Qt 运行时图标和 Windows EXE 图标。
- 选择理由：完整接入能覆盖窗口、任务栏和资源管理器，避免应用在不同位置显示默认图标。
- 影响：需要增加 Qt 资源和 Windows `.rc` 配置，并验证构建产物。

### DEC-002: 采用深色科技风视觉方案
- 阶段：方案设计
- 背景：用户选择深色科技风。
- 可选方案：简洁双色、深色科技风、Windows 原生风。
- 最终选择：深蓝底色配青色 XML、紫色转换箭头和亮绿色 Properties 元素。
- 选择理由：在深色背景上具有较高对比度，并能直接表达转换工具属性。
- 影响：SVG 与 ICO 需要保持深色底和高亮前景元素，在小尺寸下简化细节。
