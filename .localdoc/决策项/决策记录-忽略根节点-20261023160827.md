## 决策列表

### DEC-001: 将忽略选项放在转换器接口中
- 阶段：方案设计
- 背景：QML 需要把复选框状态传递给已有 XML 转 Properties 逻辑。
- 可选方案：仅在 QML 中生成/裁剪路径；增加转换器参数；增加转换器属性并由 QML 设置。
- 最终选择：为 `convert` 增加 `ignoreRoot` 参数，并保留单参数调用的默认行为。
- 选择理由：路径生成仍集中在 C++，避免 UI 复制转换规则；默认参数保持已有调用兼容，改动范围小。
- 影响：转换器单元测试可直接覆盖两种模式，QML 只负责传递复选框状态。

### DEC-002: 忽略根节点时丢弃根节点自身内容
- 阶段：需求确认
- 背景：根节点可能包含属性或直接文本，需要明确这些内容是否映射到 Properties。
- 可选方案：映射为无前缀 key；完全忽略；仅支持常规有子节点根节点。
- 最终选择：完全忽略根节点属性和直接文本，仅转换根节点的直接子节点及其后代。
- 选择理由：符合“输出中不包含根节点”的语义，避免生成空 key 或不明确的根节点内容。
- 影响：只有根节点属性/直接文本没有子节点路径时不会输出；子节点内容和现有规则不变。
