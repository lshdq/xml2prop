# 需求：忽略根节点

## 背景与目标

为 XML 转 Properties 工具增加根节点路径控制，使用户可以选择是否将 XML 根节点名称作为 Properties key 的路径前缀。

## 功能描述

### 核心功能

- 在主界面增加“忽略根节点”复选框。
- 复选框默认勾选。
- 勾选时，Properties 输出从根节点的直接子节点开始，不包含根节点名称前缀。
- 勾选时忽略根节点自身的属性和直接文本，不生成对应 Properties 条目。
- 未勾选时保持现有输出行为。

### 边界与约束

- 子节点层级、属性、重复兄弟节点下标、特殊字符转义和 UTF-8 行为保持不变。
- XML 解析失败时保持现有错误处理。
- 根节点没有可输出的子节点时，忽略根节点模式输出空字符串。

## 输入输出

输入为现有 XML 编辑器内容和复选框状态；输出为现有 Properties 编辑器内容。

示例：

- 未忽略：`<root><value>ok</value></root>` → `root.value=ok`
- 忽略：`<root><value>ok</value></root>` → `value=ok`
- 忽略时 `<root flag="x">text<value>ok</value></root>` 只输出 `value=ok`。

## 非功能需求（性能/安全/兼容性）

- 不改变现有 XML 解析复杂度和文件读写方式。
- 转换器接口的既有单参数调用保持兼容，默认不忽略根节点。
- 继续使用项目当前 Qt 6/C++17 技术栈。

## 依赖

- Qt Quick/QML 界面。
- `XmlToPropertiesConverter` 转换器及现有 Qt Test 测试框架。

## 验收标准

1. 主界面显示“忽略根节点”复选框，首次打开时已勾选。
2. 勾选后转换 `<root><value>ok</value></root>` 得到 `value=ok`。
3. 取消勾选后同一 XML 得到 `root.value=ok`。
4. 勾选后根节点属性和直接文本不出现在 Properties 输出中。
5. 现有属性、重复兄弟节点、转义、错误 XML 和文件读写测试继续通过。
