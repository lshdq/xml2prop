# 需求：应用图标

## 背景与目标

为 XML 转 Properties 桌面应用提供可识别的深色科技风应用图标，直观表达 XML 到 `.properties` 的转换功能，并完整适配 Windows 桌面应用场景。

## 功能描述

### 核心功能

- 生成可编辑的 SVG 图标源文件。
- 生成 Windows 多尺寸 ICO 文件。
- 将图标设置为 Qt 应用运行时图标，覆盖窗口标题栏和任务栏。
- 将图标嵌入 Windows EXE 文件。

### 边界与约束

- 图标应包含 XML 符号、转换箭头和 Properties 键值表达元素。
- 采用深色科技风，高对比度青色、紫色和亮绿色配色。
- 小尺寸下仍应保持主体符号可辨识。
- 不改变现有 XML 转 Properties 业务逻辑和 QML 页面行为。

## 输入输出

- 输入：无，图标由项目资源直接提供。
- 输出：`assets/xml2prop.svg`、`assets/xml2prop.ico` 及 Qt/Windows 资源接入配置。

## 非功能需求（性能/安全/兼容性）

- 使用 Qt 6 现有资源机制，不引入运行时第三方依赖。
- 保持 CMake 3.21+ 和 Windows MinGW 构建兼容。
- 运行时图标从 Qt 资源系统加载，避免依赖当前工作目录。

## 依赖

- Qt 6 Gui/QML 现有依赖。
- Windows 资源编译器及项目现有 CMake 构建工具链。

## 验收标准

- [ ] SVG 源文件存在，设计能表达 XML 转 Properties。
- [ ] Windows ICO 文件包含常用多尺寸图像。
- [ ] 应用运行后窗口标题栏和任务栏显示新图标。
- [ ] Release EXE 显示新文件图标。
- [ ] 现有 CTest 全部通过。
- [ ] 不引入业务功能回归。
